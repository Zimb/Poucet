# Exemple : une séance test, les sorties en mer à Nouméa

Premier essai de l'équipe sur une vraie idée : une app Flutter pour mutualiser les sorties en mer, devenue « va d'abord pêcher ton gros poisson ». On y voit naître Maui, d'abord figurant, puis recrue.

- `trace.json` : le mode « pour moi » et l'embauche de Maui.
- `reunions/` : les comptes rendus des scènes.
- `troupe.md` : la troupe après une séance, avec ses premiers liens.
