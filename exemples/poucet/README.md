# Exemple : Poucet cadré par lui-même

Le parcours réel qui a donné ce dépôt : 42 étapes de décisions, du premier prompt à l'équipe de personas.

- `trace.json` : le fil complet, avec les options écartées, les virages et les retours en arrière.
- `agents/` : les fiches longues de Marraine et d'Ariane, avant leur version courte.
- `entreprise/` : le premier registre, la fiche de Boucle d'or, et les épreuves d'embauche avec leurs résultats (échecs et corrections compris).
- `prompts/poucet-sim.md` : la version « sim théâtrale », écartée au profit d'un ton pro.

À lire pour voir comment l'équipe se trompe, se corrige et avance.
